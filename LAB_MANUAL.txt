AZURE PRODUCT RECOMMENDATION SWARM - LAB MANUAL

Last updated: 2026-06-03

====================================================================
1) OBJECTIVE
====================================================================

This lab helps you run and operate the Azure Product Recommendation Swarm.
By the end, you will be able to:
- Configure the application environment.
- Launch the Streamlit UI locally.
- Use Customer Assistant and Admin Catalog workflows.
- Publish a web version of this manual using GitHub Pages.


====================================================================
2) APPLICATION SUMMARY
====================================================================

This project is a Streamlit-based recommendation application that can process:
- Text requests.
- Optional voice input (Azure Speech).
- Optional image context (Azure Vision).

The app currently has two tabs:
1. Customer Assistant
   - Enter needs and request recommendations.
   - Optionally provide voice or image context.
2. Admin Catalog
   - Review catalog products.
   - Import catalog from CSV, JSON, or PDF.
   - Add products manually.
   - Sync catalog to Azure AI Search.

Core behavior:
- Recommendations are catalog-grounded.
- If Azure AI Search is unavailable, the app returns a clear no-data-store message.
- If image analysis fails, the app returns a grounded no-match response instead of guessing.

5) LOCAL SETUP
====================================================================

From the project root in PowerShell:

1. Check Python
   python --version

2. Create virtual environment (if missing)
   python -m venv .venv

3. Allow script execution for this terminal session (if needed)
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned

4. Activate environment
   .\.venv\Scripts\Activate.ps1

5. Install dependencies
   .\.venv\Scripts\python -m pip install -r requirements.txt


====================================================================
6) ENVIRONMENT CONFIGURATION
====================================================================

Create .env from .env.template and fill values.

Minimum keys required for retrieval:
- AZURE_SEARCH_ENDPOINT
- AZURE_SEARCH_API_KEY
- AZURE_SEARCH_INDEX_NAME

Optional keys:
- AZURE_OPENAI_ENDPOINT
- AZURE_OPENAI_API_KEY
- AZURE_OPENAI_DEPLOYMENT
- AZURE_OPENAI_API_VERSION
- AZURE_OPENAI_EMBEDDING_DEPLOYMENT
- AZURE_DOCUMENT_INTELLIGENCE_ENDPOINT
- AZURE_DOCUMENT_INTELLIGENCE_KEY
- AZURE_VISION_ENDPOINT
- AZURE_VISION_KEY
- AZURE_SPEECH_KEY
- AZURE_SPEECH_REGION

Security note:
- Never commit .env.
- Do not share screenshots containing API keys.


====================================================================
7) RUN THE APPLICATION
====================================================================

Option A: VS Code task
1. Open Command Palette.
2. Run "Tasks: Run Task".
3. Select "Run Streamlit Prototype".

Option B: PowerShell commands
1. Set module path
   $env:PYTHONPATH = "src"

2. Start Streamlit
   .\.venv\Scripts\python -m streamlit run app.py

Expected result:
- The app is available at http://localhost:8501


====================================================================
8) CUSTOMER ASSISTANT WORKFLOW
====================================================================

1. Enter a request in plain language.
2. Optionally upload an image.
3. Optionally record voice input.
4. Click "Get Personalized Recommendations".
5. Review:
   - Summary and guidance
   - Product cards (price, rating, value score)
   - Processing trace and extracted context


====================================================================
9) ADMIN CATALOG WORKFLOW
====================================================================

1. Open Admin Catalog tab.
2. Review product table and metrics.
3. Import catalog file (CSV, JSON, or PDF).
4. Choose Replace existing catalog on/off.
5. Click Ingest.
6. Click Sync catalog to Azure AI Search.

Manual product entry:
- Name and description are required.
- Tags, use cases, and benefits can be comma-separated.


====================================================================
10) CATALOG DATA GUIDELINES
====================================================================

Accepted import types:
- CSV
- JSON
- PDF (tabular extraction via Document Intelligence)

Recommended fields:
- id (optional)
- sku (optional)
- name or product_name or title
- category
- description
- price
- rating
- tags
- use_cases
- benefits
- image_hints

Best practices:
- Use clear product names.
- Keep descriptions specific and practical.
- Add meaningful tags (for example: cordless, pet-hair, HEPA).


====================================================================
11) TROUBLESHOOTING
====================================================================

Issue: Azure datastore unavailable message
Fix:
1. Verify search values in .env.
2. Confirm Azure AI Search index exists and is reachable.
3. Use Admin Catalog > Sync catalog to Azure AI Search.

Issue: Module import or package errors
Fix:
1. Ensure .venv is activated.
2. Reinstall packages:
   .\.venv\Scripts\python -m pip install -r requirements.txt

Issue: No image-based matching
Fix:
1. Verify AZURE_VISION_ENDPOINT and AZURE_VISION_KEY.
2. Retry with a clearer image.

Issue: Voice capture unavailable
Fix:
1. Check Streamlit version and browser microphone permission.
2. Verify AZURE_SPEECH_KEY and AZURE_SPEECH_REGION.

Issue: Updated catalog not reflected in recommendations
Fix:
1. Re-run catalog sync from Admin Catalog.
2. Retry query.
