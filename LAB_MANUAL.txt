AZURE PRODUCT RECOMMENDATION SWARM - LAB MANUAL

Last updated: 2026-06-03

====================================================================
1) START HERE
====================================================================

This is an execution-focused lab manual to set up, access, and run the app.

When you finish this manual, you will have:
1. A local environment configured.
2. The app running in Streamlit.
3. A validated recommendation workflow.

Estimated time: 15 to 25 minutes.


====================================================================
2) PREREQUISITES
====================================================================

Required:
- Windows PowerShell
- Python 3.10 or newer
- Internet connection

Required for recommendation retrieval:
- Azure AI Search endpoint, key, and index name

Optional for advanced features:
- Azure OpenAI
- Azure AI Vision
- Azure Speech
- Azure Document Intelligence


====================================================================
3) STEP 1 - GET THE PROJECT
====================================================================

If you already have the project folder locally, continue to Step 2.

If not, run:

git clone https://github.com/srisatyakrishna5/recommendation-engine.git
cd recommendation-engine

Expected result:
- You are in the project root folder.
- You can see app.py, requirements.txt, and src folder.


====================================================================
4) STEP 2 - CREATE AND ACTIVATE VIRTUAL ENVIRONMENT
====================================================================

Run from project root:

python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1

Expected result:
- Terminal prompt shows (.venv)

If activation fails due to policy, run the policy command again and retry activation.


====================================================================
5) STEP 3 - INSTALL DEPENDENCIES
====================================================================

Run:

.\.venv\Scripts\python -m pip install -r requirements.txt

Expected result:
- Dependencies install without errors.
- streamlit package is available in .venv.

Optional validation:

.\.venv\Scripts\python -m pip show streamlit


====================================================================
6) STEP 4 - CONFIGURE ENVIRONMENT FILE
====================================================================

Create .env from template:

Copy-Item .env.template .env

Open .env and set values.

Minimum required keys:
- AZURE_SEARCH_ENDPOINT
- AZURE_SEARCH_API_KEY
- AZURE_SEARCH_INDEX_NAME

Optional keys:
- AZURE_OPENAI_ENDPOINT
- AZURE_OPENAI_API_KEY
- AZURE_OPENAI_DEPLOYMENT
- AZURE_OPENAI_API_VERSION
- AZURE_OPENAI_EMBEDDING_DEPLOYMENT
- AZURE_DOCUMENT_INTELLIGENCE_ENDPOINT
- AZURE_DOCUMENT_INTELLIGENCE_KEY
- AZURE_VISION_ENDPOINT
- AZURE_VISION_KEY
- AZURE_SPEECH_KEY
- AZURE_SPEECH_REGION

Security rules:
- Never commit .env
- Never expose secrets in screenshots or logs


====================================================================
7) STEP 5 - RUN THE APPLICATION
====================================================================

Run:

$env:PYTHONPATH = "src"
.\.venv\Scripts\python -m streamlit run app.py

Expected result:
- Streamlit starts without errors.
- Local URL appears, usually http://localhost:8501

Alternative in VS Code:
1. Open Command Palette.
2. Run Tasks: Run Task.
3. Select Run Streamlit Prototype.


====================================================================
8) STEP 6 - ACCESS THE APPLICATION
====================================================================

Open in browser:
- http://localhost:8501

Expected UI:
- Header with service readiness indicators.
- Customer Assistant tab.
- Admin Catalog tab.

If the browser does not auto-open, copy and paste the URL from terminal.


====================================================================
9) STEP 7 - VALIDATE END-TO-END FLOW
====================================================================

Customer Assistant quick test:
1. Enter this prompt:
   Suggest affordable products for cleaning kitchen floors.
2. Click Get Personalized Recommendations.
3. Confirm summary, product cards, and processing trace are shown.

Admin Catalog quick test:
1. Open Admin Catalog tab.
2. Confirm current products are visible.
3. Optionally upload CSV, JSON, or PDF catalog.
4. Click Ingest.
5. Click Sync catalog to Azure AI Search.


====================================================================
10) STEP 8 - STOP THE APPLICATION
====================================================================

In the Streamlit terminal, press:
- Ctrl + C


====================================================================
11) TROUBLESHOOTING
====================================================================

Issue: App does not start
Actions:
1. Confirm (.venv) is active.
2. Reinstall dependencies.
3. Run startup command again.

Issue: Azure datastore unavailable message
Actions:
1. Verify AZURE_SEARCH_ENDPOINT, AZURE_SEARCH_API_KEY, AZURE_SEARCH_INDEX_NAME.
2. Confirm Azure AI Search index is reachable.
3. Click Sync catalog to Azure AI Search in Admin Catalog.

Issue: Voice or image feature not working
Actions:
1. Verify corresponding keys in .env.
2. Check browser microphone permissions for voice.
3. Retry with clear audio/image input.
